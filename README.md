# License Lens

纯前端开源依赖许可证兼容性分析工具。导入依赖清单后，按**开源 / 闭源分发方式**判定每条依赖的许可证风险，支持手动添加、筛选、补录与导出 Markdown 报告。

## 使用

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览构建产物
```

## 判定规则

| 许可证 | 开源分发 | 闭源分发 |
| --- | --- | --- |
| MIT / Apache-2.0 / BSD / ISC / CC0 | 兼容通过 | 兼容通过 |
| GPL-2.0 / GPL-3.0 / AGPL-3.0 | 提醒复核 | 高风险 |
| LGPL / MPL（弱 copyleft） | 提醒复核 | 提醒复核 |
| CC-BY-4.0（署名类素材许可） | 提醒复核 | 提醒复核 |
| Proprietary（专有许可） | 高风险 | 提醒复核 |
| 未识别 / 缺失 | 待补录 | 待补录 |

- **兼容通过**：保留版权声明与许可证文本即可分发。
- **提醒复核**：存在 copyleft 义务、链接/署名要求或授权范围问题，发布前需法务复核。
- **高风险**：许可证义务与当前分发方式冲突，不得直接分发。
- **待补录**：清单缺少可识别的许可证标识，需在结果行内补录后重新判定。

## 清单格式

- 每行一条：`名称@版本 许可证`（不写许可证即标记待补录），如 `react@18.3.1 MIT`
- CSV：`名称,版本,许可证`（支持首行表头）
- 直接导入 `package.json`（依赖版本会被解析，许可证统一待补录）
- 支持页面粘贴、文件选择与拖放上传

## 导出报告

Markdown 报告包含每条依赖的**依赖名、版本、许可证、风险结论、分发方式与判定理由**，并附待补录清单、判定依据说明与关键条款汇总，文件名为 `license-report-YYYY-MM-DD.md`。

## 结构：规则与展示分离

```
src/license/types.ts    领域类型（依赖 / 许可证 / 风险 / 分发方式）
src/license/catalog.ts  许可证目录、别名归一化（规则数据，新增许可证改这里）
src/license/analyze.ts  “许可证族别 × 分发方式”判定表与判定理由（规则逻辑）
src/license/parse.ts    清单解析（逐行文本 / CSV / package.json）
src/license/report.ts   Markdown 报告生成与下载
src/App.tsx             展示与交互（导入、添加、筛选、补录、导出共用同一份结果）
src/styles.css          全部样式
```

> 报告结论由清单中的许可证标识自动生成，仅供内部合规参考，不构成法律意见。
